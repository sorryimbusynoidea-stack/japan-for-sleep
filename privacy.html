Privacy Policy — YouTube Optimizer

Last updated: October 17, 2026

What this app is

YouTube Optimizer is a private tool run locally on the channel owner's own computer. It is used only by the owner of the JAPAN FOR SLEEP YouTube channel (sleep.optimalplan.jp) to analyze and manage that channel.

Data accessed

With the user's explicit OAuth consent, the app accesses, through YouTube API Services: the authorizing account's channel and video metadata (YouTube Data API v3) and YouTube Analytics reports for that channel (YouTube Analytics API). If the user grants the additional permission, it updates metadata of the user's own videos.

How data is used and stored

  • Data is used only to analyze channel performance and prepare metadata improvements for the owner.
  • Data and OAuth tokens are stored only on the owner's local computer. Nothing is sent to any server operated by the app, and no data is sold, shared, or used for advertising.
  • The user can revoke access at any time at https://myaccount.google.com/permissions, and locally stored data can be deleted at any time.

Google and YouTube

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
